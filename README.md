# Diffie-Hellman Key Exchange Simulation

## Description
A desktop software application simulating the Diffie-Hellman Key Exchange algorithm. Developed in Python using the `tkinter` GUI framework, this tool allows users to visualize how two parties (Alice and Bob) can securely generate a shared secret key over a public channel without ever transmitting their private keys. 

## Features
- **Interactive UI**: Clean and intuitive interface separated into Public Parameters, Alice's panel, and Bob's panel.
- **Real-time Computation**: Instantly calculates public keys and the final shared secret key.
- **Calculation Log**: Displays step-by-step mathematical operations including modular exponentiation for educational purposes.
- **Validation**: Automatically verifies if both generated shared secret keys match perfectly.

## Prerequisites
- Python 3.x installed on your operating system.
- `tkinter` library (this is pre-installed with standard Python distributions).
